# Validation interviews

Goal for H0–H2: talk to 5–10 teams here about whether their coding agents have stepped on each other. If almost nobody has, decide on a pivot before H2. These notes are also evidence for the Anthropic track ("a real problem, talked to people who have it"). The demo lane owns this file.

Ask:

1. Are you using coding agents on this project? How many people, how many agents?
2. Have two people's agents ever built the same thing, or two pieces that didn't fit? What happened?
3. How do you avoid it now? (Group chat, splitting by folder, not using agents in parallel…)
4. Would you install a plugin that blocks your agent until it says what it's building? What would make that annoying?
